# 📚 Mahdarti - Study Assistant

**Mahdarti Study Assistant** is a smart study aid designed to help students organize their studies, summarize lectures, and manage academic tasks efficiently and easily.

---

## 🌟 Key Features

* 📝 **Lecture Summarization & Organization:** Write and organize notes for each subject.
* 🤖 **Smart Study Assistant:** Generate questions and summarize content to aid in studying.
* 📅 **Time & Task Management:** Track study schedules and deadlines for assignments and projects.
* ⚡ **Simple & Fast User Interface:** A user-friendly, responsive design compatible with all devices.

---
